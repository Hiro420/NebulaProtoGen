# NebulaProtoGen
Protobuf schema generator for NebulaPS

---

# Usage
- Compile via `dotnet build` or Visual Studio
- If you want to use specific vendor, put the corresponding ClientConfig.json in the folder
- Run `NebulaProtoGen`. All of the schemas will be generated.
